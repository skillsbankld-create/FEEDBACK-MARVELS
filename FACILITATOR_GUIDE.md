# Facilitator guide — Feedback Marvels
Timing: welcome 2 min · test 8–10 min · split + reveal 3–5 min.
1. Open the dashboard (2026), share the link, open Projector View.
2. Watch progress; wait for everyone (late ones can be added after).
3. Press FORM THE TEAMS. Re-shuffle or swap if needed.
4. Start the board game; the highest-scoring team chooses its role first (Giver, Receiver, Judge).
Debrief: "Which style did you get? Which does the other team need?" then link to Feedback → Feedforward.
